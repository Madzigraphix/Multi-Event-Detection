Multi-Event Detection
Project Overview
The Multi-Event Fall Detection and Alert System is a wearable embedded system prototype developed to assist in identifying suspected fall incidents and facilitating emergency communication when the wearer may be unable to request help manually. The project combines motion sensing, microcontroller-based processing, GPS positioning, wireless communication, and user interaction into a compact wearable device.
The system is built around an ESP32 microcontroller, which serves as the central processing unit responsible for acquiring sensor data, evaluating movement events, managing system states, controlling alert outputs, and coordinating emergency communication. An MPU6050 accelerometer and gyroscope are used to monitor motion along three axes, capturing acceleration and rotational changes that may be associated with falls or other abnormal movement patterns.
System Operation
The system continuously monitors movement using the MPU6050. Acceleration magnitude and angular velocity are evaluated to identify suspicious movement patterns, including sudden acceleration changes, unusual rotation, possible free-fall events, and impact-related movement. Rather than relying on a single sensor threshold, the multi-event detection approach considers a combination of movement indicators to help distinguish potential falls from normal activities and reduce false alarms.
When a suspected fall is identified, the system initiates a warning phase using an audible buzzer and vibration motor. The wearer is given time to cancel the alert if the detection was accidental or if assistance is not required. If the countdown expires without cancellation, the system proceeds to emergency notification.
Emergency Communication and Location Tracking
Emergency communication is implemented using the ESP32's built-in Wi-Fi capability and the TextBee SMS gateway API. Once an emergency event is confirmed by the alert sequence, the device attempts to transmit an SMS notification to a designated contact.
The system incorporates a NEO-6M GPS module for geographical positioning. When a valid GPS fix is available, the emergency message includes the coordinates and a location link to assist in identifying the wearer's position. If GPS positioning is unavailable at the time of the emergency, the system sends an initial notification and continues monitoring for a valid location. Once GPS coordinates become available, a follow-up message is automatically sent.
User Interface and Features
An OLED display provides visual feedback about the device's operating status, including monitoring state, device identification, date and time, GPS information, and alert status. Three push buttons provide manual emergency activation, cancellation of a pending alert, and system reset.
The prototype also incorporates a unique device identification feature to distinguish individual units and a battery monitoring function intended to help track the power supply condition.
Engineering and Development
The project integrates embedded programming, sensor interfacing, I²C and UART communication, power management, wireless networking, GPS data processing, alert control, and wearable mechanical enclosure design. It demonstrates how different hardware and software subsystems can be combined to create an autonomous safety-oriented device.
Intended Application and Limitations
The system is intended as an experimental assistive technology prototype that explores automated fall recognition and emergency notification. It is not a certified medical device or a replacement for emergency response systems. Detection performance, false alarms, GPS accuracy, network availability, battery endurance, and wearable comfort require further testing and validation before practical deployment.
Future development may include improved movement classification, expanded activity testing, optimization of power consumption, more robust communication handling, improved enclosure design, and additional reliability testing.
